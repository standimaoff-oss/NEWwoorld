# NEWwoorld AI Studio

Собственная нейросетевая ИИ-система и десктопная студия (**Windows `.exe` + WebGL/Three.js 3D CAD Studio**) для:
1. **Профессиональной 3D CAD геометрии (`NEWwoorld-CadGPT`)** — нейро-символическая модель предсказывает CAD-операции и параметры, а математическое ядро собирает **100% замкнутые (watertight) квад-доминантные сборки** (`non_manifold_edges == 0`), чего не дают обычные mesh/Marching-Cubes генераторы.
2. **Генерации фото по частям (`NEWwoorld-PhotoPartNet`)** — послойный композиционный синтез в 5 явных этапов (Небо/Свет → Дальний фон → Главный объект → Детали/Отражения → Нейронный финиш и ACES Filmic-тонирование) с просмотром каждого слоя.
3. **Распознавания картинок, текста и Image-to-3D (`NEWwoorld-VisionOCR`)** — обученная CNN + Attention модель классифицирует сцену/деталь, сегментирует строки и распознаёт кириллицу + латиницу + цифры + инженерные символы (`Ø`, `±`), а также преобразует чертёж/фото в 3D CAD.
4. **Масштабирования до нескольких миллиардов параметров (`1.2B`, `3.0B`, `6.8B-MoE`, `3.1B MMDiT`)** — готовые PyTorch FSDP-архитектуры для обучения на GPU-кластерах.

---

## Честно о масштабе и железе

- **Что обучено и работает прямо сейчас (`NEWwoorld Core v1`)**:
  В репозитории реализован собственный автоград-движок (`newwoorld_ai/nn/` на NumPy/BLAS + SafeTensors), и все 3 модели реально обучены на синтетических мультиязычных датасетах (`1,004,954` обученных параметров суммарно, чекпоинты в `models/checkpoints/*.safetensors`):
  - `NEWwoorld-CadGPT-Core` (`460,614` параметров) — точность классификации архетипов CAD на валидации: **100%**.
  - `NEWwoorld-PhotoPartNet-Core` (`352,992` параметров) — точность сцен на валидации: **100%**, генерация по 5 слоям.
  - `NEWwoorld-VisionOCR-Core` (`191,348` параметров) — точность сцен: **100%**, точность распознавания 122 классов символов (RU/EN/цифры/знаки): **84.8%** + контекстное разрешение омоглифов.
- **Почему модели на несколько млрд параметров не обучены внутри песочницы**:
  Обучение 1.2B–7B параметров с нуля требует GPU-кластера (например, 4×–8× A100/H100 80GB, сотни ГБ датасетов ABC/Objaverse-XL/LAION и недели вычислений), тогда как облачная песочница имеет 2 vCPU и 3.8 ГБ ОЗУ без GPU. Поэтому в `newwoorld_ai/scale_billion/` подготовлены полные PyTorch-архитектуры с точным расчётом параметров и `torchrun` FSDP-скриптом для запуска на вашем GPU-кластере.

## Windows `.exe` приложение

В папке `windows/` уже лежит скомпилированный **64-битный Windows GUI исполняемый файл**:
- **`windows/NEWwoorldStudio.exe`** (`PE32+ x86_64`, ~557 КБ):
  - При запуске в папке репозитория автоматически находит Python / `.venv` и запускает **полный нейросетевой бэкенд (`NEWwoorld Core`)**, открывая студию в отдельном окне приложения (Edge/Chrome `--app`) + окно управления Win32.
  - Если Python на ПК не установлен — **не падает**: автоматически запускает встроенный прямо в `.exe` нативный C11 HTTP-сервер, встроенный сжатый Three.js 3D CAD-вьюер и генератор водонепроницаемых шестерён/фото-слоёв + экспорт `.OBJ` и `.STL`!
- **`windows/NEWwoorldStudio.bat`** — запуск в 1 клик с автоустановкой Python-зависимостей для полного нейросетевого режима.
- **`windows/build_pyinstaller.bat`** и **`.github/workflows/build-windows-exe.yml`** — сборка полностью автономного однофайлового `NEWwoorldStudio-Full.exe` с Python и весами внутри.

## Локальный запуск (Linux / Windows / macOS)

```bash
python -m venv .venv
# Linux/macOS: source .venv/bin/activate | Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -e . --no-deps

# Обучить модели с нуля (перезапишет models/checkpoints/*.safetensors):
python -m newwoorld_ai.training.train_all

# Запустить 3D CAD & AI Студию:
python scripts/launch_studio.py --host 0.0.0.0 --port 8000
```

## Тесты и проверка параметров (1.2B–6.8B)

```bash
pytest -v
python scripts/verify_billion_configs.py

# Запуск обучения 3.0B модели на GPU-кластере (8x A100/H100):
torchrun --nproc_per_node=8 -m newwoorld_ai.scale_billion.train_fsdp --preset cad_3.0b
```
