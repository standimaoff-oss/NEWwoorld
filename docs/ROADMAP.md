# План развития Aquaflux

## 0.1.0 — прототип (готово)

- [x] Каркас Forge 1.20.1, CI, релизные артефакты
- [x] Решатель мелкой воды: масса, течение, трение, CFL, границы регионов
- [x] Пресеты 16/32/64 для физики и текстуры
- [x] Свой блок, жидкость, ведро, творческая вкладка
- [x] Движок мира: активные регионы, бюджет, сон, восстановление массы из блоков
- [x] Гладкая поверхность, бортики, палитра по глубине, волны от игрока
- [x] Автоопределение Iris/OptiFine и режимы совместимости
- [x] Постепенная замена ванильной воды по флагу
- [x] Тесты ядра

## 0.2.0 — качество воды (следующий шаг)

- [ ] Пена у берегов и на водопадах (вторая полоса геометрии + альфа)
- [ ] Нормал-мап и flow-map: течение читается по текстуре, а не только по геометрии
- [ ] Отражения неба (cubemap) и Fresnel-затемнение на глубине
- [ ] Каустика на дне (лёгкая, по глубине)
- [ ] Подводный туман по глубине, а не ванильный
- [ ] Звук: журчание у камней, всплеск от шага

## 0.3.0 — объём

- [ ] Слой «вертикальная вода»: водопады и пещеры, несколько уровней на колонку
- [ ] 3D-солвер для активной области (MAC-сетка) с обменом массой с 2.5D-слоем
- [ ] Лава как второй экземпляр решателя (вязкость, свечение)
- [ ] Ныряние: дробная высота воды для плавания и коллизий

## 0.4.0 — полная замена

- [ ] Океаны и аквиферы: генерация с конечной массой, граничные условия на горизонте
- [ ] Дождь и снег как источник массы (маленький, но реальный)
- [ ] Лёд: замерзание верхнего слоя, таяние обратно
- [ ] Совместимость: Create, Flywheel, рыбалка, кораллы, редстоун рядом с водой
- [ ] Миграция сохранений: старые миры с ванильной водой

## 1.0.0 — производительность и полировка

- [ ] GPU-солвер (compute 4.3+) с CPU-fallback
- [ ] Многопоточный шаг регионов
- [ ] Профилирование: Spark/JFR-бенчмарки в CI (headless-мир)
- [ ] Настройки в игре (Cloth Config / встроенный экран)
- [ ] Локализация: ru/en, ещё пара языков

## Идеи на потом

- Водяные мельницы и турбины (редстоун-сигнал от потока)
