## Что реализовано в графике

- PBR-материалы с color / normal / roughness, мокрые поверхности и потёртые вывески под дождём;
- объёмная трава с ветром, цветовыми вариациями, чанковым отсечением и плавным LOD;
- канал 36 × 300 м: анимированные волны, отражение сцены, блики, прибрежная пена, рябь от дождя;
- бамбук, пальмы, лиственные деревья, кустарники, новогодняя ёлка с подсветкой;
- 9 точек осмотра, включая открытую витрину «便民超市» с полками, товаром и кассой;
- 36 китайских вывесок, окна с кондиционерами, машины и пешеходы (InstancedMesh);
- время суток, ясная/дождливая погода, капли на стёклах, процедурные облака;
- **GTAO** и **SSGI** на высоком качестве: экранная трассировка одного отскока непрямого
  света по G-буферу (половинное разрешение, временное накопление, depth-aware размытие,
  ограничение вклада и затухание с дальностью). Это не аппаратный RTGI — свет из-за края
  кадра не приходит, но цветной bounce в тенях есть;
- три пресета качества, орбита / ходьба WASD / сенсорный джойстик и обзор касанием,
  скриншот, HUD со статистикой, автотур, диалог «О макете», `H` — чистый кадр.

## Как запустить

- **HTML:** двойной щелчок по `China_Preview.html` — работает через `file://` без интернета.
- **PWA:** открыть живой предпросмотр (порт 3000) в Chrome → «Установить приложение»;
  после установки работает офлайн, в том числе на Android.
- **APK:** `dist/ChinaPreview.apk` → установить на телефон (нужен System WebView с WebGL2).
  Разрешение `INTERNET` не запрашивается, всё внутри APK.
- **EXE:** `dist/ChinaPreview.exe` — portable, установки не требует, Windows x64.
- **Пересобрать всё:** `node preview/build.mjs`; `cd android && ./gradlew assembleDebug`;
  `cd desktop && npm install && npm run dist`. CI делает это автоматически.

## Что было исправлено по ходу

- Выбеливание на «Высоком» + GTAO: прямой рендер и HDR-композер считали туман в разных
  цветовых пространствах — теперь все кадры идут через линейный композер; штатное
  мультипликативное смешивание GTAO на HalfFloat заменено явным шейдером с `NoBlending`.
- `Reflector` клонировал uniform-объекты — вода не анимировалась и не реагировала на погоду;
  привязаны общие часы, убрана белая полоса отражения неба у берега.
- Две «дыры» в земле у торцов канала и камера внутри кроны в точке «Пальмы».
- Витрина сделана полым павильоном с полом, потолком и внутренним светом.
- Панель настроек перекрывала кнопки режимов при 1024×640 после добавления SSGI —
  добавлены `max-height` и прокрутка.

## Честные ограничения

- **Настоящий EXE/APK игры не пересобраны и не могут быть пересобраны в этом дереве:**
  в репозитории нет `src/` (C++17/raylib 5.5), `android/` (Gradle + NDK) и `desktop/`
  исходного проекта — только готовый `ShopSim.exe` 6,6 МБ. Здесь лежат новые обёртки
  вокруг нового рендера, а не новая версия симулятора магазина. Экономика, сохранения,
  карта OSM и игровая логика не тронуты.
- **Sketchfab-модели не импортированы:** коннектор в этой среде недоступен, ссылки
  использованы как ориентиры. Вся геометрия процедурная, ключ API не встроен.
- **Аппаратного RTGI нет** — реализован SSGI, экранная аппроксимация одного отскока.
- Нет теста на физическом Android-устройстве и замера FPS на целевом железе.
- Текстуры помечены CC0 по данным зеркала `petroulacl/fps-buildings-env-kit`; перед
  коммерческим релизом стоит свериться с оригинальными страницами ambientCG.
