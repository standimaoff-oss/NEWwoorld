# Скриншоты веб-сборки (0.6.3)

Это не рендеры и не мокапы — это реальные кадры из игры, снятые в headless Chromium
(WebGL2 через ANGLE/SwiftShader) скриптом `game_shot.cjs`. Скрипт ждёт `window.__ready`,
даёт игре 4 секунды на прогрев чанков, снимает PNG и печатает статистику кадра
(`calls`, `tris`, ошибки шейдеров из консоли).

| файл | что на кадре | как снято |
|---|---|---|
| `01_city_day.png` | город днём с крыши: облака, крыши с парапетами | `?fresh=1&hour=12&quality=high&nohud=1&cam=21,40,230,0,-6` |
| `02_street_day.png` | уровень глаз: газон, фасад, окна | `?fresh=1&hour=12&quality=high&nohud=1&cam=21,1.8,150,0,0` |
| `03_shop_window.png` | витрина магазина вблизи: полки с товаром за стеклом | `?fresh=1&hour=12&quality=high&nohud=1` |
| `04_winter_city.png` | зима: снег, заснеженные крыши, тучи | тот же кадр + `season=winter` |
| `05_winter_street.png` | зима вблизи: наст, снегопад | `cam=21,1.8,150,0,0` + `season=winter` |
| `06_sunset.png` | закат: розовое небо, тёплые облака | `hour=19`, `cam=21,30,230,0,-6` |
| `07_night.png` | ночь: окна, звёзды, ёлка | `hour=22`, `cam=21,26,230,0,-6` |
| `08_hud.png` | интерфейс: деньги, часы, задачи, подсказки | `?fresh=1&hour=12&quality=high` |

## Как повторить

```bash
# 1) сервер из папки game/
cd game && python3 -m http.server 8124 --bind 0.0.0.0

# 2) скриншот (нужны puppeteer-core и @sparticuz/chromium)
node game_shot.cjs \
  'http://127.0.0.1:8124/?fresh=1&hour=12&quality=high&nohud=1&cam=21,40,230,0,-6' \
  city.png 960 540
# сезон передаётся последним аргументом:  ... city.png 960 540 'season=winter'
```

`cam=x,y,z,tx,ty,tz` — позиция камеры и точка взгляда, `hour` — время суток,
`quality` — пресет графики, `nohud=1` — без интерфейса, `fresh=1` — без сохранения.

Цифры fps в этих кадрах (10–16) — программный растеризатор SwiftShader, а не
видеокарта: они годятся для сравнения версий между собой, но не как «фпс в игре».
