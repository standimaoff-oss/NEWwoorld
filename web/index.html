Архитектура масштабирования до нескольких млрд параметров (PyTorch FSDP)

          
В песочнице (2 vCPU / 3.8 ГБ ОЗУ, без GPU) физически невозможно обучить модель на миллиарды параметров — поэтому локально обучено ядро Core (1.0M параметров), а в newwoorld_ai/scale_billion/ подготовлены точные PyTorch-архитектуры (RoPE + GQA + FlashAttention/SDPA + MoE + Regional MMDiT) для запуска на GPU-кластере.
